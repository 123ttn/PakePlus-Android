# TabBar 图标

请在此目录放置以下图标文件：

## 必需图标

| 图标 | 文件名 | 尺寸 | 说明 |
|------|--------|------|------|
| 首页 | home.png / home-active.png | 81x81 | 首页 TabBar 图标 |
| 模块 | modules.png / modules-active.png | 81x81 | 模块管理 TabBar 图标 |
| 设置 | settings.png / settings-active.png | 81x81 | 设置 TabBar 图标 |

## 图标要求

- 格式：PNG
- 尺寸：81x81 像素（2倍图，实际显示 40.5x40.5）
- 背景透明
- 建议使用纯色图标或渐变图标

## 推荐图标库

- [IconFont](https://www.iconfont.cn/)
- [Remix Icon](https://remixicon.com/)
- [Phosphor Icons](https://phosphoricons.com/)

## 临时解决方案

如果暂时没有图标，可以：
1. 在 pages.json 中移除 tabBar 配置
2. 或使用 emoji 作为临时图标
